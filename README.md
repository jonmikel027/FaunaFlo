# FaunaFlo

## Descripción
FaunaFlo es un prototipo de página web educativa dedicado a la divulgación de la fauna y la flora de nuestro planeta. Su objetivo es ofrecer un espacio visual, sencillo y entretenido en el que los usuarios puedan descubrir diferentes especies de animales y plantas, conocer sus características y aprender algunas de sus curiosidades más sorprendentes.

El proyecto está dirigido a todas aquellas personas que sienten curiosidad por el mundo natural, especialmente a niños y no tan niños que quieran acercarse a la biodiversidad de una forma accesible y divertida.

La idea es que los usuarios puedan aprender mientras exploran e interactúan con la plataforma, descubriendo nuevos datos sobre las especies a través de filtros por zonas geográficas, hábitats, comportamientos y otras características. Se busca convertir la consulta de información en una experiencia de descubrimiento, donde la curiosidad invite a seguir explorando.

## Estructura del Prototipo
La web está organizada en tres vistas principales, conectadas mediante un menú de navegación común.

* **index.html**: Página de inicio. Presenta el proyecto FaunaFlo y permite acceder directamente a las secciones de Fauna y Flora mediante tarjetas con imágenes y enlaces.

* **fauna.html**: Catálogo de animales. Incluye fichas con fotografías, nombres comunes y científicos, además de un buscador y un selector de hábitats.

* **flora.html**: Catálogo de plantas. Comparte una estructura similar a la sección de Fauna, con fichas de especies vegetales, un buscador y un selector de tipos de plantas.

Además, el proyecto incluye una página provisional de **«Página en construcción»** para representar las futuras fichas detalladas de las especies.

## Tecnologías Utilizadas
* HTML5
* CSS3

## Enfoque Técnico
El proyecto se ha desarrollado a partir de bocetos iniciales, creando primero la estructura HTML y aplicando posteriormente los estilos CSS.

Entre los recursos utilizados destacan:

- Flexbox para organizar tarjetas, navegación y otros elementos.
- Selectores CSS de etiqueta, clase, identificador y combinados.
- Propiedades display y position para controlar la distribución y el posicionamiento.
- Media queries para adaptar el diseño a dispositivos móviles.
- Efectos hover y transiciones para mejorar la interacción.
- Clases reutilizables para compartir estilos entre las páginas de Fauna y Flora.
